## Summary of key requirements

The HDC wants paper cumulative records replaced by a secure, easy-to-use system that students fill out during enrollment.

| Area          | What the respondent said                                                                                              |
|---------------|-----------------------------------------------------------------------------------------------------------------------|
| Problem       | Paper forms take 10–15 min each; 6,000+ enrollees; records are hard to find and track                                 |
| Main feature  | Computerized cumulative record that students fill out (online or offline)                                             |
| Users         | Students fill out and edit their own records; HDC staff view them                                                     |
| Reports       | Summary of psychological concerns (e.g., counts for depression, anxiety)                                              |
| Notifications | Alert staff when a student submits a new record                                                                       |
| Routing       | Records sorted automatically by college based on the student's program                                                |
| Access        | HDC head sees all colleges; each counselor sees only their assigned college; other departments request data by letter |
| Security      | Mental health and family data must stay confidential                                                                  |
| Integration   | Unsure; the university has its own system                                                                             |
| Timeline      | No set date; driven by accreditor recommendation                                                                      |
| Budget        | None allotted yet; possible with board approval                                                                       |
| Success       | Shorter enrollment, more private and secure data, no intensive training needed                                        |

**Follow-ups:** HDC will share the counselor-to-college assignment once new counselors arrive (around the third week), and a sample cumulative record form.
